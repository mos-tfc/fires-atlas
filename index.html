Download fires-atlas-site.zip

Upload to GitHub (no tools needed)

  1. Unzip the file on your computer. You get index.html, app.js, README.md, build.sh, .gitignore and the folders src and functions.
  2. Open the repository, press Add file → Upload files.
  3. Drag everything inside the unzipped folder (not the folder itself) into the page. Folders keep their structure. .gitignore may be hidden on your computer; it is optional.
  4. Commit message “Fires Atlas website”, commit directly to main. It replaces the placeholder index.html and README.md.
